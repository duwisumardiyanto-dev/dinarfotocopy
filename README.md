![DINAR Fotocopy](logo-dinar.jpg)

- 🌐 **Fullscreen Edge-to-Edge Design** - Layout modern dan megah

## 🚀 Cara Menjalankan

### Metode 1: Menggunakan Node.js (Recommended)

```bash
# Install dependencies
npm install

# Jalankan server
npm start
```

Website akan berjalan di: **http://localhost:3000**

### Metode 2: Menggunakan Batch File (Windows)

Double-click file `start-server.bat`

### Metode 3: Manual dengan npx

```bash
npx serve -l 3000
```

## 📋 Teknologi yang Digunakan

- **HTML5** - Struktur halaman modern

- **Vanilla JavaScript** - Interaktivitas tanpa framework
